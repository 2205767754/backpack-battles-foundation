# 发布检查表

1. 仅使用本仓库白名单目录，不从旧交付包整体 git add。
2. 运行 `node --test`、`node scripts/check-publication.mjs` 和 demo。
3. 人工检查 `git diff --cached` 和 `git ls-files`。本库检查器只检查文件范围、常见凭证形态和本机绝对路径，不是完整秘密扫描器。
4. 不上传游戏资源、密钥、真实数据集、真实运行日志或个人信息。
5. 不复制本机 git 全局 email；提交使用 GitHub noreply 地址。
6. 默认创建私有新仓库，不修改既有仓库、不强推、不自动公开。
7. 首个标签固定为 v0.1.0；以后以提交和测试证据追溯变更。
8. 当前无运行后台，无端口监听；测试如开启本地服务必须在 finally 中关闭。

## 进一步公开前

需要检查数据来源许可、代码权利、选定 LICENSE，以及扫描完整 Git 历史。首次上传不代表授权开放全部旧项目内容。

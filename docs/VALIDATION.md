# 验收层级

| 层级 | 本库范围 | 不能替代什么 |
| --- | --- | --- |
| 数据契约 | 字段、缺失语义、回合序列、SHA256 和大小 | 来源内容真实性、授权许可 |
| 几何合法 | 越界、同层重叠、包格覆盖、原生占格转换 | 星位效果是否适用、战斗收益 |
| 状态一致 | 购买确认事件幂等、版本冲突、库存守恒 | 上游内存识别正确、真实点击成功 |
| 完整效果 | 未实现 | 菠萝盾/彩鸟等复杂组合的专项效果验收 |
| 策略效果 | 未实现 | 陌生状态、多回合偏移、与大师对比 |
| 实机闭环 | 未在本库执行 | 游戏内桥接、真实购买、完整 R1～R18 |

`node --test` 使用虚构样例；下载测试注入构造的 Fetch Response，验证哈希/重试/落盘逻辑，不验证远程站点的 HTTPS 传输。不会访问游戏、抓取真实数据或修改游戏状态。

本次独立基础库的单元测试结果与旧 v6 的离线/浏览器回放结果是不同证据，不能相互冒充。特别是“原有 51 项 + 新 11 项”等历史数字不算本库测试数量。

未解决：交易轨迹缺失、复杂效果映射、战力评估可靠性、分布偏移、训练环境及策略能力、内存桥实机适配。

# 背包乱斗基础工具库

这是从 v66.161-v6 项目经验中整理、重新实现的**独立基础库**，不是完整游戏助手，也不是已经达到大师水平的 AI。

## 目前包含

- 布局数据契约：来源、坐标、缺失语义、布局与交易证据分离。
- 原生占格转换、边界/同层重叠/包格覆盖检查，以及纯几何星位命中查询。
- 经外部确认的购买事件回放：幂等、状态版本检查、库存守恒、失败不推进。
- HTTPS 下载、SHA256/大小校验、有限重试、断点复用和校验后原子落盘。
- 人工构造的样例、可失败的回归测试、发布范围检查。

## 快速开始

安装 Node.js 22 或以上版本；无第三方运行依赖，无需 npm install。

```sh
node --test
node scripts/check-publication.mjs
node scripts/demo.mjs
```

授权后在本机下载一个明确的 manifest 条目：

```sh
node scripts/download.mjs --manifest /absolute/path/manifest.json --id YOUR_EXACT_BUILD_ID --base https://YOUR_AUTHORIZED_HOST/assets/layouts/ --out /absolute/path/local-data
```

下载命令不会自动抓取全站，仓库不含真实对局、物品资源库或真实玩家信息。

## 必须读的边界

1. 新库是**经过整理的新实现**；本库单元测试通过不代表旧 EXE 调用了这些模块，现有工具没有被替换。
2. 回合盘面不能还原逐次购买、出售、刷新、折扣、保留和当时钱包。缺失必须用 null，不能用空数组假装“没有发生”。
3. 坐标采用 `r=行、c=列`。原始 `[x,y]` 为 `[列,行]`；占格使用来源库该朝向的 `[dx,dy]`，不擅自重新归一化锚点。
4. 几何星位命中不代表游戏效果生效：类型过滤、消耗、锁定、时机、去重和战斗收益仍需独立效果模型。
5. 对账模块**不从金币/件数变化猜测交易**，只接受上游已确认事件。它不是内存桥，也不验证上游来源真实性。
6. 本库没有完整战斗模拟器、策略训练、强化学习、全局最优证明或实机 18 回合验收。
